# Contributing to Angelia

Thanks for your interest! Angelia is pre-alpha, so the design still moves. A few rules keep things smooth:

1. **Discuss first.** Open an issue (or a thread in [Discussions](https://github.com/angelia-dev/angelia/discussions)) before starting non-trivial work, so we agree on the approach before you write code.
2. **Conventional Commits.** Use `type(scope): summary`, e.g. `feat(source/pypi): support yanked releases`, `fix(dispatcher): retry on 429`. Common types: `feat`, `fix`, `docs`, `refactor`, `test`, `chore`, `ci`.
3. **DCO sign-off.** Every commit must be signed off to certify the [Developer Certificate of Origin](https://developercertificate.org/): use `git commit -s`, which adds `Signed-off-by: Your Name <you@example.com>`.
4. **Small pull requests.** One logical change per PR, with tests and docs where relevant.

By contributing you agree that your contributions are licensed under the Apache-2.0 license of the repository, and you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).

Security issues: please do **not** open a public issue. See [SECURITY.md](SECURITY.md).
